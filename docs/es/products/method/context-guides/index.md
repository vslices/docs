# Guías de Contexto

Las Guías de Contexto (*Context Guides* en inglés) explican cómo VSlices Method puede aplicarse en distintos contextos de trabajo.

!!! principle "Principio guía"

    Las Guías de Contexto no definen rutas de adopción obligatorias.
    Ayudan a elegir un punto de partida útil según la situación real del equipo.

## Propósito

Un contexto de trabajo cambia cómo debería aplicarse VSlices Method.

Comenzar desde un escenario no digitalizado no es lo mismo que incorporarse a un proyecto de software existente. Introducir Method en trabajo en curso tampoco es lo mismo que usarlo desde el comienzo.

Los Context Guides ayudan a responder preguntas como:

* ¿A qué tipo de situación estamos entrando?
* ¿Qué incertidumbre domina este contexto?
* ¿Qué riesgos deberíamos evitar?
* ¿Qué modalidad de VSlices Design puede ser útil primero?
* ¿Qué conocimiento debería preservarse temprano?
* ¿Cómo puede ayudar Method sin crear ceremonia innecesaria?

## Cómo usar estas guías

Usa un Context Guide como ayuda de orientación. No lo trates como una checklist.

Una guía puede sugerir puntos de partida útiles, riesgos comunes y posible soporte documental, pero el equipo todavía debería decidir según el contexto real.

El objetivo no es aplicar Method completamente. Es preservar suficiente continuidad para tomar la siguiente decisión responsable.
