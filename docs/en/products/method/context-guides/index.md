# Context Guides

Context Guides explain how VSlices Method can be applied in different work contexts.

!!! principle "Guiding principle"

    Context Guides do not define mandatory adoption paths.
    
    They help teams choose a useful starting point according to the real situation they are entering.

## Purpose

A work context changes how VSlices Method should be applied.

Starting from a not digitized scenario is not the same as joining an existing software project. Introducing Method into ongoing work is also not the same as using it from the beginning.

Context Guides help answer questions such as:

* What kind of situation are we entering?
* Which uncertainty dominates this context?
* Which risks should we avoid?
* Which VSlices Design modality may be useful first?
* Which knowledge should be preserved early?
* How can Method help without creating unnecessary ceremony?

## How to use these guides

Use a Context Guide as orientation support. Do not treat it as a checklist.

A guide may suggest useful starting points, common risks, and possible documentation support, but the team should still decide according to the real context.

The goal is not to apply Method completely. It is to preserve enough continuity to make the next responsible decision.
