# Bootstrap history

Esta carpeta conserva evidencia que originó la superficie provisional de definición de suite.

Su contenido no tiene autoridad por encima de las definiciones distribuidas en `../foundations/`, `../mechanisms/`, `../products/`, `../relationships/` y `../promotion/`.

Se preserva para poder reconstruir:

- qué problema motivó la superficie común;
- qué distinciones aparecieron antes de separar ownership;
- cómo evolucionó la organización interna del conocimiento;
- qué conocimiento todavía puede no haber sido promovido.

Cuando exista `vslices/suite`, esta evidencia puede conservarse como historia de bootstrap o trasladarse a una superficie histórica equivalente.
