# Semantic Pressure

## Estado

`candidate`

## Ownership

`VSlices Suite`

## Propósito

**Semantic Pressure** es un mecanismo de VSlices para interrogar deliberadamente el significado de un fenómeno hasta hacer visibles distinciones, supuestos, restricciones, autoridad, consecuencias y evidencia requerida que permanecían implícitos.

No busca maximizar preguntas ni profundidad.

Debe aplicarse hasta:

- reducir la incertidumbre relevante; o
- hacer explícito que falta conocimiento que debe obtenerse y no puede inventarse responsablemente.

## Preguntas típicas

- ¿Qué significa exactamente este término?
- ¿Qué lo distingue de otro concepto parecido?
- ¿Quién tiene autoridad para establecer este hecho?
- ¿Qué debe ser cierto antes o después?
- ¿Qué evidencia se necesita?
- ¿De dónde puede obtenerse?
- ¿Qué puede derivarse y qué debe observarse?
- ¿Qué puede fallar de forma esperada?
- ¿Qué cambia como consecuencia?

## Relación con productos

### Design

Puede utilizar Semantic Pressure para profundizar entendimiento y tensionar modelos o fronteras candidatas.

### Method

Puede decidir cuándo, cuánto y con qué objetivo aplicar Semantic Pressure durante trabajo real.

### Docs Standard

Puede preservar las distinciones, incertidumbres, decisiones o evidencia descubiertas mediante el mecanismo.

### Framework

Puede beneficiarse de sus resultados cuando significado, autoridad, evidencia o comportamiento deben materializarse como semántica ejecutable.

### Tooling

Puede eventualmente asistir la aplicación del mecanismo, pero una automatización no adquiere por ello autoridad para decidir qué significado es correcto.

## Historia provisional

Semantic Pressure fue descrito inicialmente como técnica candidata de Method.

La evidencia conceptual actual sugiere que su identidad atraviesa más de un producto, por lo que se reclasifica provisionalmente como mecanismo suite-level.

Esta reclasificación permanece candidata y debe ser validada mediante uso real.
